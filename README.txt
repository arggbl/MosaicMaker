------- SETUP -------
The PIL and tqdm libraries are required to operate this program.

To operate, create a file to put the MosaicMaker.py file in.
Create three files, titled "Tiles", "Input", and "Output".

"Tiles" is where the program draws image files to create the mosaic, it is recommended to put lots of images in this file.
"Input" can ONLY HAVE ONE image file in it at a time, it is what the program will make a mosaic of.
"Output" is where the finished file goes.

----- OPERATION -----
Reccomended settings: 150 grid size, 30 accuracy.
Note: there is a hidden setting called "scale" that you can find at the top of the file, it determines the output size.
the larger scale is the larger the image and, by extension, the larger the tiles.

This program is VERY, VERY BUGGY.
Expect a noticeable amount of runtime.
